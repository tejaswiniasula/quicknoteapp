# Smart Notes Pro

A modern full-stack note-taking application built using **FastAPI**, **SQLite**, **HTML**, **CSS**, and **JavaScript**.

## Features

* Add Notes
* Edit Notes
* Delete Notes
* Search Notes
* Dark Mode
* Responsive UI
* SQLite Database
* REST API using FastAPI

## Technologies Used

* FastAPI
* SQLite
* SQLAlchemy
* HTML5
* CSS3
* JavaScript

## Project Structure

```
quicknoteapp/
│
├── backend/
│   ├── main.py
│   ├── crud.py
│   ├── database.py
│   ├── models.py
│   ├── schemas.py
│   └── requirements.txt
│
└── frontend/
    ├── index.html
    ├── style.css
    └── script.js
```

## How to Run

### Backend

```
cd backend
uvicorn main:app --reload
```

### Frontend

Open `frontend/index.html` using Live Server.
